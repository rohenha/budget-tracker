## Features

### Budget

- Custom categories with color and icon
- Pie chart visualisation of expenses and cash inflows
- Edit / delete categories

### Expenses

- Import expenses from CSV (bank export)
- Create, edit and delete expenses
- Filter by period and category
- Daily expenses chart

### Loans & Credits

- Track loans with borrowed amount, interest rate and duration
- Auto-calculated monthly payment, total interest and amortisation schedule
- Repayment progress visualisation

### Investments _(coming soon)_

- Portfolio overview with real-time values via Yahoo Finance
- DCA automation

### Crypto _(coming soon)_

- Portfolio overview with real-time values via CoinGecko
- DCA automation

### Dashboard _(coming soon)_

- Global net worth summary across all modules

## Installation

```bash
# Clone the repo
git clone https://github.com/rohenha/budget-tracker.git
cd budget-tracker

# Install dependencies
npm install

# Set up environment
cp .env.example .env

# Generate app key
node ace generate:key

# Run migrations
node ace migration:run
```

### Required environment variables

| Variable        | Description                                |
| --------------- | ------------------------------------------ |
| `APP_KEY`       | Generated by `node ace generate:key`       |
| `DB_CONNECTION` | `mysql` or `sqlite`                        |
| `DB_HOST`       | Database host (MySQL only)                 |
| `DB_PORT`       | Database port, default `3306` (MySQL only) |
| `DB_USER`       | Database user (MySQL only)                 |
| `DB_PASSWORD`   | Database password (MySQL only)             |
| `DB_DATABASE`   | Database name (MySQL only)                 |
